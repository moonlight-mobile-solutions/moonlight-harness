# Design skills

Product design files and the bridge between design and code.

| Skill | Use it to |
|---|---|
| [`figma-feature-file-structure`](figma-feature-file-structure/SKILL.md) | Organize a product's Figma file by feature and status, build screens from code through the Figma MCP (skills/design/figma-feature-file-structure) |
| [`ux-writing`](ux-writing/SKILL.md) | Write and review interface copy (buttons, errors, empty states, forms, onboarding) with voice, tone and accessibility (skills/design/ux-writing) |

For web pages (landing pages, sites, dashboards), install the third-party `design-taste-frontend`; see [third-party.md](../../third-party.md).
