# Common skills

Apply to every Moonlight project, whatever the stack. Stack skills build on these and name them as their base.

| Skill | Use it to |
|---|---|
| [`coding-principles`](coding-principles/SKILL.md) | Structure code in any language (skills/common/coding-principles) |
| [`spec-driven-development`](spec-driven-development/SKILL.md) | Size the work and write a spec before medium or large changes (skills/common/spec-driven-development) |
| [`github-issue-templates`](github-issue-templates/SKILL.md) | Write an issue (skills/common/github-issue-templates) |
| [`github-issue-development`](github-issue-development/SKILL.md) | Start or finish an issue on the project board (skills/common/github-issue-development) |
| [`git-workflow`](git-workflow/SKILL.md) | Branch and commit (skills/common/git-workflow) |
| [`quality-gate-workflow`](quality-gate-workflow/SKILL.md) | Verify before "done" or a commit (skills/common/quality-gate-workflow) |
| [`pair-programming-git-review`](pair-programming-git-review/SKILL.md) | Review staged changes before committing (skills/common/pair-programming-git-review) |
| [`pull-request-description`](pull-request-description/SKILL.md) | Describe a PR (skills/common/pull-request-description) |
| [`repository-pattern-persistence`](repository-pattern-persistence/SKILL.md) | Put persistence behind a repository, Python backend and Flutter frontend (skills/common/repository-pattern-persistence) |
| [`subagent-delegation`](subagent-delegation/SKILL.md) | Delegate operational work to cheaper sub-agents and review it; set up the `executor` agent (skills/common/subagent-delegation) |
| [`lgpd-brasil`](lgpd-brasil/SKILL.md) | Check personal-data handling against Brazil's LGPD: legal bases, data subject rights, incidents, international transfer (skills/common/lgpd-brasil) |
