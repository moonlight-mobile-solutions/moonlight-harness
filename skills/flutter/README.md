# Flutter skills

Dart and Flutter apps (mobile and web). Load [`coding-principles`](../common/coding-principles/SKILL.md) together with `flutter-coding-principles`.

| Skill | Use it to |
|---|---|
| [`flutter-coding-principles`](flutter-coding-principles/SKILL.md) | Dart idioms, widget composition, Cubit state (skills/flutter/flutter-coding-principles) |
| [`flutter-clean-architecture`](flutter-clean-architecture/SKILL.md) | Create a feature, UseCase or entity (skills/flutter/flutter-clean-architecture) |
| [`flutter-dependency-injection`](flutter-dependency-injection/SKILL.md) | Register a service, wrap an SDK, write a fake (skills/flutter/flutter-dependency-injection) |
| [`flutter-go-router-navigation`](flutter-go-router-navigation/SKILL.md) | Declare routes, guards, navigate from a Cubit (skills/flutter/flutter-go-router-navigation) |
| [`flutter-jwt-bloc-auth`](flutter-jwt-bloc-auth/SKILL.md) | Self-hosted JWT auth with refresh (skills/flutter/flutter-jwt-bloc-auth) |
| [`flutter-firebase-email-link-app-links`](flutter-firebase-email-link-app-links/SKILL.md) | Firebase email link sign-in with Android App Links (skills/flutter/flutter-firebase-email-link-app-links) |
| [`flutter-responsive-design-system`](flutter-responsive-design-system/SKILL.md) | Responsive layout and Material 3 theming (skills/flutter/flutter-responsive-design-system) |
| [`flutter-accessibility`](flutter-accessibility/SKILL.md) | Build and test accessible UI (skills/flutter/flutter-accessibility) |
| [`flutter-arb-l10n`](flutter-arb-l10n/SKILL.md) | Add user-facing strings and translations (skills/flutter/flutter-arb-l10n) |
| [`flutter-testing-conventions`](flutter-testing-conventions/SKILL.md) | Unit, widget and Maestro tests, coverage (skills/flutter/flutter-testing-conventions) |
| [`android-adb-manual-verification`](android-adb-manual-verification/SKILL.md) | Verify on an Android device through ADB (skills/flutter/android-adb-manual-verification) |

Quality gate commands: `flutter analyze`, `dart format .`, `flutter test`, `dart run build_runner build -d` when codegen changed.
